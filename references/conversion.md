# 提取转换详解（提鞋增刀王）

> "提鞋增刀王"是课件《1 记忆基础》的五法口诀：**代替、谐音、增减字、倒字、望文生义**。
> 本文件把五法展开成可操作的判断顺序，并补上从课件画面里归纳出来的十路处理表。

---

## 1. 转换的目标

转换不是为了"把句子变好玩"，是为了**把会掉的词，钉在一个能画出来、也能读回来的东西上**。

两个验收关：

| 关 | 问什么 | 不合格 |
|---|---|---|
| 画得出 | 一笔能成形？轮廓单一？ | "水很清"——只能画一片蓝，等于没转 |
| 读得回 | 看见它，能直接读出原字？ | 燕子——画得出，但读不出"谁裁出" |

两关都过才算成立。只过第一关，是画了个壳子。

---

## 2. 五法有强弱

| 法 | 怎么转 | 锁得死不死 | 例 | 代价 |
|---|---|---|---|---|
| **谐音** | 用一个同音具体物 | 最强，一字对一字，零误差 | 阳→羊、庐→炉、富→福、桐→铜、蔽→壁、泠→铃 | 要找到同音物 |
| **增减字** | 加一字或减一字 | 强，原字还在 | 上蔽→上**壁** | 略改字面 |
| **倒字** | 换个顺序读 | 强，字序变了 | 朱颜→颜朱 | 容易读别 |
| **望文生义** | 按字面想画面 | 中，靠"看着像"，一人一读法 | 愁→愁云、茫然→雾 | 读法不唯一 |
| **代替** | 任选一物代表 | 最弱，要记两遍（物＋它代表啥） | 春风→剪刀、独绝→竖拇指 | 多一条记忆链 |

**做的顺序：先谐音 → 增减字/倒字 → 望文生义 → 最后才代替。**

大多数人的毛病是一上手就用代替，结果满图东西，每样都得额外记一笔"它代表什么"。

### 2.1 用铃铛验一遍这条排序

课件《与朱元思书》11 号桩画的是铃铛，对应"泉水激石，泠泠作响"。

若按"代替"，意思是"铃铛代表响声"，那喇叭、锣、鼓都行，为什么偏偏是铃铛？

**因为"泠"和"铃"同音（líng）。** 换喇叭，响是响，锁不住"泠"。

所以它不是代替，是谐音——一字对一字，不用记额外关系。这就是"好记"的来源：**能谐音就别代替。**

（此层为对画面的推断，课件未加说明。）

### 2.2 直取：不转才是最省

原句本来就是实物词的，一律直取，不要画蛇添足。

| 原词 | 处理 |
|---|---|
| 急湍甚**箭** | 画箭羽，不转 |
| 有时见**日** | 画太阳，不转 |
| 望峰**息心** | 画一颗心，不转 |
| 游**鱼**细石 | 画鱼、画石子，不转 |

17 桩里直取与谐音占了大半，真正靠代替的只有少数——**这套图好记，是因为少用代替。**

## 3. 十路处理表（抽象词怎么办）

| 类型 | 手法 | 例 |
|---|---|---|
| 感官属性（冷、寒、凉） | 画符号 | 寒气弧线、雪花、水波纹 |
| 评价词（独绝、最、好） | 画手势 | 竖拇指＝第一 |
| 看不见的动作（裁、蔽） | 画痕迹 / 同音代物 | 刀口直边 / 壁 |
| 看不见的东西本体（风、愁、梦） | 给脸 / 给形 / 装泡泡 | 有脸的云、愁云、回忆泡 |
| 专名（扬州、富阳） | 谐音代物，可两跳 | 羊、福羊 |
| 数量程度（万条、千丈、高） | 用画法，不用字 | 画密、画满、冲出画框 |
| 时间（三月、夜、四万八千岁） | 计时器 | 日历、月亮、石碑 |
| 声音（乡音、泠泠、子规声） | 声音符号，按语气挑 | 音符（平和）、感叹号（急促）、铃铛（清响） |
| 说的话、问的话 | 气泡写原字 | "客从何处来""闲人少" |
| 角色（经纶世务者） | 给可读身份，不给解释 | 渔翁、光脚小孩 |

### 3.1 声音符号怎么挑

同样是声音，符号不一样，因为**语气不同**。

| 语气 | 符号 | 出处 |
|---|---|---|
| 平和、悠长 | 音符 ♪ | 《回乡偶书》"乡音无改" |
| 急促、喧闹 | 感叹号 !!! | 《乡村四月》"子规声里" |
| 清亮、叮咚 | 铃铛 | 《与朱元思书》"泠泠作响" |

### 3.2 手势怎么用

评价类抽象词，画手势最省，因为一看就懂、人人会画。

| 意思 | 手势 |
|---|---|
| 最棒、第一 | 竖拇指 |
| 不、没有 | 摇手 |
| 来、归来 | 招手 |
| 静、噤声 | 食指竖在嘴前 |

## 4. 专名的处理

### 4.1 原则：地名锁音，不锁形

地名的信息在读音上，不在样子上。

| 画法 | 锁住什么 | 能确定是哪座城吗 |
|---|---|---|
| 城墙轮廓 | "城"这个类别 | 不能（长安、洛阳、扬州都成立） |
| 一只羊 | "扬"这个音 | 能 |

**画它的样子，等于丢掉地名本身。** 人名、器物名同此理。

### 4.2 单字专名：一物即可

《送孟浩然之广陵》的扬州：只画一只羊（扬→羊），"州"是通名，不用管。

### 4.3 双字专名：一个实体 ＋ 一条属性

地名两个字都是专名时，**不必画两样东西**，画一样，再给它一个颜色或装饰。

| 地名 | 实体（谐第二字） | 属性（谐第一字） |
|---|---|---|
| 富阳 | 羊（阳） | 身上的红色/福气（福→富） |
| 桐庐 | 炉（庐） | 铜褐色（铜→桐） |

**通名可省**（州、城、县、山、水、关），专名不能省。判断顺序：先划出哪几个字是专名，专名几个字就配几个钩。

### 4.4 谐音可以两跳

《与朱元思书》第 9 句"负势竞上"：负势 → 富士 → 富士苹果。

先谐到一个大家都认识的专名，再由这个专名带出能画的东西。条件是中间那一跳必须人人认识，否则链就断。

## 5. 语法结构照抄成图形结构

这是最省事的一条：**句子的语法是现成的，把它照搬到画面上，图形结构就自动对了，不必另编顺序。**

| 句式 | 图形结构 | 例 |
|---|---|---|
| A 至 B | 两端各一物，中间连一条桥/路 | 自**富阳**至**桐庐**：左端福羊，右端铜炉，中间拱桥＝"至" |
| A 与 B | 并排两物，中间不连 | 牵牛与织女、狼与豺 |
| A 似 B | 一物套进另一物的形状 | 月似弓：弓背即月牙 |
| A 在 B 上 | 上下堆叠，下托上 | 枯松倒挂倚绝壁 |
| A 出 B | B 在画里，A 从 B 里出来 | 细叶谁裁出 |
| A 满 B | B 画满，A 铺满全屏 | 绿遍山原、白满川 |

## 6. 转换的克制

**只转会掉的那个词。**

一句话若已有两样实物撑住骨架，就停手。抽象词用最小符号补——一条弧线、一个点、一个问号即可，不要每词一个大图案。

判断哪些词"会掉"：

1. 修饰词（银、冷、凉、碧、残、孤、尽）
2. 专名（牵牛、织女、富阳、桐庐）
3. 疑问词（谁、何、安在）
4. 否定词（不相识、无人、莫开）
5. 数量词（万条、千丈、四万八千岁）

名词本身、常见动词（走、看、坐）一般不会掉，不必转。

---

## 7. 三条禁令

1. **不换词。** 图上出现的字必须是原句的字。"客"不能写成"您"。
2. **不改动作。** 原文"坐看"就别画"卧看"。
3. **不硬凑。** 转换不出来的句子，标明"钩子弱"并给补法，不要塞一个读不回来的东西充数。
