# poem-memory · 古诗词与短文画图记忆

把一首诗（或一篇文言短文）拆成**一句一个画面元素**，用四格图或定桩法固定顺序，闭眼走一遍图就能背下来。

不是玄学联想，是一套有判据、能自检的流程：画得出来、读得回去。

## 四步法

**通读理解 → 提取转换 → 绘制成图 → 闭目忆图**（懂、拆、装、验）

| 步 | 做什么 | 通过标准 |
|---|---|---|
| 通读理解 | 先读懂意思、典故、生僻字 | 能用自己的话讲一遍 |
| 提取转换 | 每句提 1 个关键词，转成能画的具体物 | 每个词都能落到画面上 |
| 绘制成图 | 按句数和句子关系选容器，编号落位 | 每个元素都有唯一桩位 |
| 闭目忆图 | 闭眼走图，看着画面读回原句 | 句子能原样读回 |

## 转换引擎：「提鞋增刀王」

课件五法口诀，按强弱排序使用：

**提**（代替）> **鞋**（谐音）> **增**（增减字）> **倒**（倒字）> **王**（望文生义）

抽象词优先走谐音出具体物，画面感弱的再增减字／倒字，实在不行才望文生义。专名可走两跳谐音（富阳 → 有福气的羊），通名能省则省。

## 选容器的判据

| 句数与结构 | 用什么 |
|---|---|
| 4 句，并列 | 四格分镜 |
| 8 句，成对推进 | 上下两排 / 整幅图 |
| 空间移动、一句一景 | 一整幅连续画面 |
| 时间推进 | 四格（早→晚、春→冬） |
| 40 句以上，或对仗密集 | 定桩法（固定桩位表）/ 分幕 |

句子关系决定图形结构：并列 → 定桩，空间 → 整幅，时间 → 四格。

## 输出长什么样

以《泊船瓜洲》为例，方案包含四块：

1. **分句表**：原句 / 关键词 / 转换物 / 桩位编号
2. **转换表**：说明每个词用的哪一路（谐音、代替、增减字…）
3. **逐格画面**：文字描述每格画什么、在什么位置、什么颜色
4. **走图路线 + 自检四条**：按什么顺序看图，以及"读不回原句"时的返工点

```
~/.workbuddy/skills/poem-memory/
├── SKILL.md
└── references/
```

或直接用 `release/poem-memory-v1.0.0.zip` 导入。

## 适用与不适用

- 适合：五言/七言绝句、律诗、词、篇幅中等的文言文（如《与朱元思书》《蜀道难》）。
- 不适合：纯议论无画面的现代议论文；以及不想花时间看图、只想"多读几遍"的场景。
